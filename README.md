VM Using Azure Key Vault
📌 Overview

This project demonstrates how to securely manage secrets, credentials, and sensitive configuration data for an Azure Virtual Machine using Azure Key Vault.

🎯 Objectives
Understand Azure Key Vault and its purpose.
Store sensitive information securely in Azure Key Vault.
Configure secure access between an Azure Virtual Machine and Key Vault.
Retrieve secrets without hardcoding credentials in scripts or application code.
Follow Azure security best practices.
🛠️ Technologies Used
Microsoft Azure
Azure Virtual Machine (VM)
Azure Key Vault
Azure Identity and Access Management (IAM)
Azure Role-Based Access Control (RBAC)
🚀 Implementation Steps
Create an Azure Virtual Machine.
Create an Azure Key Vault.
Enable a managed identity for the virtual machine.
Grant the VM identity the required permissions to access Key Vault secrets.
Store a sample secret in Azure Key Vault.
Access and retrieve the secret securely from the VM.
Verify that access works as expected.
🔐 Security Benefits
Avoid hardcoding secrets in scripts and application code.
Centralize secret management.
Use managed identities to reduce credential management.
Apply least-privilege access controls.
Improve the security of Azure resources.
📚 Learning Outcomes

This project provides hands-on experience with Azure infrastructure, identity management, secret storage, and secure communication between Azure services.
